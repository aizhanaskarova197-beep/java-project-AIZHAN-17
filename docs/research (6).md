# Research: Dodo Pizza Kazakhstan

## 1. Ұйым туралы

**Dodo Pizza** — 2011 жылы Сыктывкарда құрылған халықаралық пиццерия желісі. Қазақстанда 2015 жылдан жұмыс істейді, 2025 жылы елде 100-ден астам пиццерия болды. Тапсырыс өз бұлттық жүйесі **Dodo IS** арқылы өңделеді: тапсырыс асхана планшетіне түсіп, кезеңдерден өтеді (жайма, толтырма, пеш, орау), содан кейін жеткізіледі.

## 2. Анықталған проблема

**Тапсырыс құрамындағы қателер:** клиент басқа пицца алады немесе пицца піспей шығады. Бұл наразылыққа және тапсырысты қайта жасауға әкеледі.

Дәлел: Dodo пиццерияларына қалдырылған пікірлер (Restoclub, Ресейдегі пиццерияларға): https://www.restoclub.ru/msk/place/dodo-picca/opinions

## 3. Ұсынылатын шешім

Құрам қателерін азайтатын Java консольдік жүйесі: тапсырыс құрамы нақты сақталады, чекте толық көрсетіледі, асханаға дәл сол құрам беріледі, бос тапсырыс қабылданбайды, статус тек ретімен өзгереді.

## 4. Жобаның мақсаты

Dodo Pizza Kazakhstan тапсырыстарындағы құрам қателерін азайтатын жеңілдетілген жүйені Java тілінде әзірлеу.

## 5. Жобаның міндеттері

1. Ұйымды зерттеп, проблеманы анықтау.
2. UML диаграммаларын салу (Use Case, Class, Sequence).
3. Мәзірді CSV файлынан жүктеу, тапсырыс жасау және чек шығару.
4. Асхана кезегін, статустарды және курьерді автоматты тағайындауды жасау.
5. Тапсырыстарды файлға сақтау, ерекше жағдайды (`EmptyOrderException`) өңдеу.
6. JUnit тесттерін жазу, жобаны GitHub-қа жүктеу.

## 6. Қолданылатын техникалар мен технологиялар

Java 17, Maven, JUnit 5, Git/GitHub, draw.io, CSV файлдар. ООП (абстракция, мұрагерлік, полиморфизм, инкапсуляция), интерфейс, абстракт класс, коллекциялар (`ArrayList`, `HashMap`, `Queue`), exception.

## 7. Күтілетін нәтиже

Жұмыс істейтін Java қосымшасы мен үш UML диаграммасы. Демода көрсетіледі: чектегі және асханадағы құрам бірдей, бос тапсырыс өтпейді, статус ретін бұзып өзгермейді. GitHub-та кемінде 10 commit.
