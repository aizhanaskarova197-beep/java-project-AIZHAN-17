# Dodo Pizza Kazakhstan: тапсырыс қабылдау жүйесі

## Жобаның мақсаты
Dodo Pizza Kazakhstan тапсырыстарында клиентке басқа пицца берілуін (мысалы, Пепперони орнына Гавай) болдырмайтын жеңілдетілген консольдік ақпараттық жүйе (Java 17).

## Зерттелген ұйым
Dodo Pizza: 2011 жылы құрылған халықаралық пиццерия желісі, Қазақстанда 2015 жылдан жұмыс істейді. Толық сипаттама: [docs/research.md](docs/research.md).

## Мүмкіндіктер
- мәзірді `data/menu.csv` файлынан жүктеу;
- тапсырыс жасау, позиция қосу және жою, пицца өлшемін таңдау (25 / 30 / 35 см);
- құрамы бар чек (`Bill`);
- **қаптаманы тексеру**: аспаз қаптамаға салған позицияларды енгізеді, жүйе оны тапсырыс құрамымен салыстырады; сәйкес келмесе `WrongItemException` (Пепперони орнына Гавай), тексерілмеген тапсырыс берілмейді;
- бос тапсырыс қабылданбайды (`EmptyOrderException`);
- асхана кезегі (FIFO), статустар NEW → COOKING → READY → DELIVERING → DONE;
- курьер автоматты тағайындалады (бос курьерлер кезегі);
- тапсырыстар `data/orders.csv` файлына сақталады және қайта іске қосқанда жүктеледі.

## Іске қосу
Талап: JDK 17+ және Maven.

```
mvn compile
mvn exec:java
mvn test
```

IntelliJ IDEA-да: `src/main/java/kz/dodo/app/ConsoleApp.java` файлын ашып, `main` әдісінің жанындағы жасыл үшбұрышты басыңыз.

Бағдарламаны жоба түбірінен іске қосыңыз (`data/` папкасы осы жерде болуы керек).

## VS Code-та іске қосу
1. JDK 17 орнатыңыз (Eclipse Temurin) және VS Code-та **Extension Pack for Java** кеңейтімін орнатыңыз.
2. `File -> Open Folder` арқылы жоба түбірін (`pom.xml` бар папка) ашыңыз.
3. `src/main/java/kz/dodo/app/ConsoleApp.java` файлын ашып, `main` үстіндегі **Run** батырмасын басыңыз (немесе F5).
4. Терминалда мәзір шығады. **10** санын енгізсеңіз, проблеманың шешімі автоматты түрде көрсетіледі (Пепперони орнына Гавай қатесі).
